# 26 전전반 체육대회 · 전기공학과 개총/회식 체크

휴대폰으로 바로 여는 참석 체크 앱. 명단 31명이 앱 안에 들어 있어서 아무것도 안 올려도 바로 뜬다.

**https://brightwindow.github.io/jjb26-check/**

## 쓰는 법
1. 링크 열고 → 공유 → **홈 화면에 추가** (한 번만 하면 데이터 없어도 열림)
2. 아래 칸에 내 이름 입력 (누가 체크했는지 남음)
3. 이름 옆 `개총` / `회식` 버튼 눌러서 체크. 다시 누르면 해제.

## 회장단끼리 합치기
각자 폰에서 체크 → `합치기` → **내 체크 보내기** → 나온 링크를 단톡방에 올림 →
그 링크를 누른 사람 폰에 자동으로 합쳐진다. 같은 사람이 겹치면 **나중에 누른 쪽**이 이긴다.

## 오프라인
- 처음 한 번 열어두면 서비스워커가 앱을 저장해서 비행기모드/지하에서도 열린다.
- 체크는 폰 안(localStorage)에 저장 → 인터넷 끊겨도 계속 체크된다.
- 인터넷 돌아오면 `합치기` 링크로 서로 맞추면 됨.

## 그 외
- 청/백 팀, 종목(축구·피구·줄다리기·미션·계주)은 체육대회 명단 그대로.
- `···` → 개총/회식 명단 카톡용 텍스트 복사, CSV 저장, 전체 초기화.
